AOYAGI HOME Ver3.3 完成版

【今回の主な修正】

■ ホーム
・家族6人を必ず2列×3行で表示
・写真部分以外は、カードの枠内すべてをタップしてミッションへ移動
・写真部分だけカメラを起動

■ 風船ゲーム
・初期版のテンポ感に近づけて、開始直後から複数のマークを表示
・約0.36秒ごとにポンポン出現
・押すとすぐ次が出現
・出現位置は画面全体からランダム
・表示時間は2秒
・ドクロ、得点差、レアアイコンの光る演出を維持
・押したときに「+5」「-5」などの得点演出を表示

■ 絵合わせ
・6ペア、8ペア、10ペアから難易度選択
・最初の5秒間はすべて表向き
・間違いは5回まで
・クリア時に星評価

■ わが家のレシピ帳
・主食の初期値を「ごはん」に設定
・季節と味付けの初期値を「指定なし」に設定
・「麺」を選んだ場合は麺料理だけを表示
・「パン」を選んだ場合はパン料理だけを表示
・味付けを指定した場合は、その味付けの料理だけを表示
・各料理カードに「詳しいレシピ」ボタンを追加
・保存済みURLがある料理はそのページを開く
・URLがない料理は、料理名＋レシピ＋調味料＋分量でネット検索
・食材選択、自由入力、わが家への保存、作った回数の記録は継続

■ 交代のお知らせ
・5分から7分へ変更
・AOYAGI HOMEが画面に表示されている間だけ計測
・別アプリ、ホーム画面、画面ロックなどで見えなくなったら停止
・再び表示したときは、新しく7分を計測
・時間は累積しない
・ミニゲーム中は割り込まず、ゲーム終了後に表示
