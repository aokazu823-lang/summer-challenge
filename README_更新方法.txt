【データ引っ越し】
同じiPad・Safari・URLなら、パパ・ママモードの「データ」から旧データを検出して引き継げます。
実行前に旧データの自動バックアップをブラウザ内に作ります。

【注意】
Safariの「履歴とWebサイトデータを消去」をすると保存データも消える可能性があります。定期的にバックアップを書き出してください。
テレビタイマー中はSafariを画面に出したまま使うのが確実です。
